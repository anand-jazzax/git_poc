# Prime Number Finder

This script finds the i-th prime number.

## Usage

```bash
python3 prime_number.py <i>
```

Replace `<i>` with the position of the prime number you want (e.g., `5` for the 5th prime).

Example:

```bash
python3 prime_number.py 5
# Output: The 5-th prime number is: 11
```
